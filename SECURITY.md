# Security policy

This repository is the source of https://www.id.life. Only the live site (the `main` branch as deployed) is supported.

## Reporting a vulnerability

Please report security issues privately, never in a public issue or pull request:

- on GitHub: **Security** tab of this repository > **Report a vulnerability** (private vulnerability reporting);
- or through the contact listed in https://www.id.life/.well-known/security.txt.

Include the affected URL, steps to reproduce and the impact you observed. Please do not access data that is not
yours, degrade the service, or submit the site's forms with real people's details while testing.
